# Legacy portfolio (2022)

The first version of this portfolio: plain HTML, CSS and JavaScript, built during the Microverse
program and deployed to Netlify.

It is kept here for reference only — nothing in this folder is part of the current build. The live
site is now the Blazor WebAssembly app in [`../src/Portfolio`](../src/Portfolio).

To view it, open `index.html` in a browser.
